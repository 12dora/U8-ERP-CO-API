U8-ERP-CO-API：用友 U8+ REST API

把用友 U8+ 的业务组件发布为 HTTP API（OpenAPI 3.1）。An HTTP / REST API for Yonyou U8+ ERP.

  • 单据：销售、采购、库存、生产、质量、应收应付单据的读写、审核和参照生单
  • 财务与档案：总账凭证、核销与制单、基础档案、现存量和只读报表
  • 集成：按操作员权限、预演、幂等键、机器可读错误；Python 客户端与命令行、MCP 服务、单据事件
概览 快速开始 接口参考（文字版） MCP 服务 单据事件 架构 配置参考 已知限制 U8 行为说明 测试 常见问题 openapi.json 源代码

非官方项目，与用友网络科技股份有限公司没有关联。「用友」「U8」「U8+」是其商标，本站提及仅为说明兼容对象。

文档里的服务器地址 https://u8co.example.com 只是占位，请换成你的部署地址； 所有请求都要带 Authorization: Bearer <JWT>。
